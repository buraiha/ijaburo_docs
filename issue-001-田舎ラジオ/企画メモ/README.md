# 企画・調査メモ

`企画メモ/` は、その回に取り上げるネタを溜めておく場所です。放送予定回ごとに話題・特集案・イベント候補・出典・調査結果・保留事項を蓄積します。まだ回が決まっていないネタもここで管理し、採用回が決まったら対応する回のメモへ整理します。

- 日付とテーマ・状態が分かるファイル名にする。
- 出典、確認日、決定事項、未確認事項、次の対応を残す。
- 採用後は放送回・プロットへの参照を追記し、調査の履歴を残す。
- `../plots/` は、実際に放送するときの台本を保存する場所。ここに溜めたネタを選び、進行・セリフ・掛け合い・告知を台本にまとめ、レビューによる修正と実際の放送内容を記録する。
