# 企画・調査メモ

一般的なアイデア・未採用の構想・調査を蓄積します。取り上げる指示を受けたネタは、日付未定でも[収録準備](../収録準備/README.md)に登録します。店舗の基本情報は[店舗資料](../店舗資料/README.md)へリンクします。

- 日付とテーマ・状態が分かるファイル名にする。
- 出典、確認日、決定事項、未確認事項、次の対応を残す。
- 採用後は放送回・プロットへの参照を追記し、調査の履歴を残す。
- `../plots/` は、実際に放送するときの台本を保存する場所。収録準備と関連企画メモのネタを選び、進行・セリフ・掛け合い・告知を台本にまとめ、レビューによる修正と実際の放送内容を記録する。
