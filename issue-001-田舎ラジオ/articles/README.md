# ブログ記事

このフォルダには「issue-001-田舎ラジオ」に関連するブログ記事を保存します。

## 保存方法

1本の記事につき `YYYYMMDD_記事名/` を作成し、本文を `原稿.md` に保存してください。写真・画像がある場合は、その記事フォルダ内に `images/` を作成します。一つのIssueに複数の記事を保存できます。

日付は原稿の作成日とし、後からフォルダ名を変更しないようにします。構成の相談や進捗は関連Issueで管理し、公開後は記事フォルダのREADMEなどに公開日・公開URLを記録してください。

共通ルールは[リポジトリのREADME](../../README.md#ブログ記事の管理)を参照してください。原稿の保存だけではウェブサイトに投稿されません。
