## 登録・更新ルール

- 日付確定：`YYYYMMDD_テーマ_収録ネタ.md`。月指定：`YYYYMM_テーマ_収録ネタ.md`。日付未定：`日付未定_テーマ_収録ネタ.md`。
- 新規ファイルと一覧への登録を同時に行う。指定日・月・順序・ユーザー指示と制作側の仮予定・状態・次の対応を区別して残す。
- 店舗の基本情報・公式URL・確認情報は店舗資料へリンクし、準備資料に複製しない。本書側では、その回の扱い・追加調査・構成案を蓄積する。
- 日程決定・変更時は改名し、全ての参照と一覧を更新する。指示を黙って削除・完了扱いにしない。
- 放送後は実際の採用内容・公開日・公開番号・プロットへのリンクを追記し、準備資料も履歴として保持する。
- 台本の承認・生成・公開は従来のフローに従う。ここへの登録だけではプロットや公開の承認にならない。
