毎回、全行とリンク先の個別資料を確認するための入口です。詳細の正本は各ファイル、共通ルールは [RADIO_HARNESS.md](../RADIO_HARNESS.md) に置きます。情報収集対象であることと、毎週放送することは区別します。

- 新規登録・改名・予定変更時は、この一覧と個別資料を同時に更新する。
- 告知開始待ち・未確認・休業中も一覧から落とさない。
- 各回のプロットに全店舗の確認結果と採否・理由を記録する。詳細な手順はハーネスの「資料を分けても取りこぼさないための管理規定」に従う。
