## 資料のナンバリング

4桁、10番飛ばしでナンバリングします。

```text

```

## 議事録について

議事録は以下のツリーで管理します。

```text
議事録  
├── 20241028_ラジオ会議.md  
└── {以下逐次作成}
```

## 企画・調査メモ

[企画メモ](企画メモ/README.md) は、その回に取り上げるネタを溜めておく場所です。`plots/` は、実際に放送するときの台本を保存する場所です。企画メモのネタを台本にまとめ、レビューによる修正と実際の放送内容を記録します。収録メモは `収録メモ/` に保存します。

## 制作・公開運用ハーネス

番組制作の共通ルールは [RADIO_HARNESS.md](RADIO_HARNESS.md) を正本として管理します。毎回の情報収集・企画・台本作成・レビュー・音声制作・最終確認・公開は、このハーネスに従って進めます。ナンバリング資料とは別に、継続して更新する運用文書です。

## 店舗・施設の資料

[店舗・施設の全件一覧](店舗資料/README.md)から個別資料へ辿れます。毎回の制作時に一覧全件と個別資料を確認し、告知指示・特集予定をプロットへ引き継ぎます。新しい資料は一覧への登録と同時に追加します。

## 写真・画像素材

[素材インデックス](images/README.md)に写真原本・月替わりサムネイル候補・採用結果を管理します。毎月の選定会議でユーザーが採用案を決めます。
