対象: https://www.inabu-jaburo.jp/ / テーマ Globalway Green（globalway）

## 依頼・承認範囲

記事に設定されたカテゴリーを複数表示し、それぞれをクリックすると同じカテゴリーの記事一覧へ移動する。未設定の場合は空の枠を出さない。プラグインの追加や記事へのカテゴリーの付け替えは行わない。

## 変更前とバックアップ

- 対象ファイル: `wp-content/themes/globalway/parts/report/single.php`、`parts/report/archive.php`。
- 変更前: `gw_category_name()` で一つのカテゴリー名を出力し、リンクがない。カテゴリー未設定でも空のspanが出力される。
- 取得元: 本番のWordPressテーマエディター。2026-11-17取得。
- 取得方法: Safariのコード欄全選択・コピー→TextEditのプレーンテキスト欄へ貼付け→全内容を取得。行番号付き・仮想スクロールで省略されたコード表示は使用しない。
- `before/` に全内容を保存。single.phpは末尾のlinknav、archive.phpは末尾のget_footerまで含むことを確認した。
- 事前確認: 既存のカテゴリーURL `/report/report_category/small-hydro-power-generation/` は自己紹介のみを表示する。記事一覧の仕組み自体は変更不要。
- Azure側の既存SSH接続は調査のみ。対象サイトはDNS上AWS Elastic Beanstalkであり、Azure上のファイルには変更していない。

## 予定変更

WordPressのカテゴリー取得・正規リンク取得APIを使い、全カテゴリーを表示する。カテゴリー名とURLはエスケープする。未設定・取得失敗時は枠を出さない。差分はカテゴリー出力部分に限定する。

## 切り戻し

1. 追加変更を止め、対象ファイルの現行内容と `after/` を比較する。
2. この修正以外の更新がなければ、`before/parts/report/single.php` と `before/parts/report/archive.php` の内容をそれぞれ同じ本番テーマファイルへ復元する。更新が混在している場合は `changes.patch` の該当差分だけを逆適用する。
3. WordPressの保存成功を確認し、必要な場合は対象ページのキャッシュを削除する。
4. `/report/`、記事265・267、カテゴリー別一覧を開き、変更前の表示と記事本文・リンクの動作へ戻ったことを確認する。
5. 切り戻し理由・日時・対象・操作・結果を本書へ追記する。
