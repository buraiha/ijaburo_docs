# ブログ記事

このフォルダには「issue-005-小水力発電」に関連するブログ記事を保存します。

## 保存方法

記事は、このフォルダ直下に `YYYYMMDD_記事名.md` として保存してください。記事ごとのサブフォルダは作成しません。一つのIssueに複数の記事を保存できます。

日付は原稿の作成日とし、公開後もファイル名を維持します。写真・画像が必要な場合は、Issue直下の既存の `images/` などを利用し、記事から相対リンクで参照してください。

構成の相談や進捗は関連Issueで管理し、公開後は記事ファイルに公開日・公開URLを記録してください。

共通ルールは[リポジトリのREADME](../../README.md#ブログ記事の管理)を参照してください。原稿の保存だけではウェブサイトに投稿されません。
